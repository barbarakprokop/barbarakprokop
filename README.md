## How I work

**Question what's worth building.** Understand the actual problem before defending a solution.

**Build directions in code.** Test how products work, not only how their screens look.

**Ship to V1.** Make complexity manageable without making everything generic.

**Tools:** Figma · React Native · Expo · TypeScript · Supabase · ChatGPT · Claude Code · Codex · n8n · Make

<sub>The public project repositories contain selected technical examples and architecture documentation. The full application repositories remain private.</sub>
