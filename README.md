
# Barbara K. Prokop

**PRODUCT DESIGNER & BUILDER · AI PRODUCTS & WORKFLOWS**

I design products from the inside out.

I'm interested in what actually needs to be built, how it should work, and where the complexity can disappear.

My work moves between product design, AI workflows and implementation. I question the premise, test ideas by building them, and turn the useful ones into working products.

## Selected work

### prmpt. | AI Cooking Lab

A conversational cooking app built around a simple idea: cooking with AI should feel like a conversation, not another interface to manage.

I designed and built the iPhone application, from the interaction model and visual direction to React Native implementation and AI integration.

**Status:** Working iPhone app, submitted for App Store review.

[Explore prmpt.](https://barbarakprokop.com/prmpt/)

### JointLift

A two-person accountability app designed to make shared goals easier to manage without turning them into another project management system.

I designed and built the iOS MVP using React Native, Expo, TypeScript and Supabase, including accounts, invitations and shared progress.

**Status:** Working MVP, approved for external TestFlight testing.

[View case study](https://barbarakprokop.com/productdesign/jointlift/)

### Concrete Sets

An iPhone and Apple Watch workout timer designed to be fast, focused and usable without an internet connection.

I designed and built the application with React Native and Expo, working through offline behaviour, Live Activities and Apple Watch interaction.

**Status:** Tested through TestFlight and submitted to the App Store.

[View case study](https://barbarakprokop.com/productdesign/case-study-concrete-sets/)

### Manual Generator

An AI-assisted workflow for turning scattered installation information into structured, reviewable manuals.

I redesigned a process that previously took two to three days, first using n8n and connected tools, then moving toward a simpler conversational approach.

The target preparation time is approximately one to two hours. Missing information is flagged for human review rather than invented by AI.

[View case study](https://barbarakprokop.com/productdesign/case-study-manual-generator/)

### Agent Studio

A multi-agent editorial system built around five distinct roles: Idea Partner, Researcher, Creative Director, Writer and Editor.

I designed and implemented the workflow to explore how specialized agents can collaborate while keeping editorial judgment and important decisions with people.

**Status:** Working system in active development.

[View case study](https://barbarakprokop.com/productdesign/agent-studio-case-study/)
